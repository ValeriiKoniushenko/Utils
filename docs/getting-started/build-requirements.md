## Build Requirements

> - [🏠 Go Home](../index.md)
> - [👈 Go Parent Page](index.md)

Needed settings\programs on your system are:
- cmake 3.30 >=
- clang 18.1.8 >= | gcc 14.2.1 >= 
- Python 3.13.2 >=

For better experience:
- Setup ```core.autocrlf=true``` for git environment

PS: MSVC has partial support for this project.
